## Product Purpose

## Positioning

The repository describes a database combining flexible JSON documents, native graph relationships, and semantic search through CleaveQL. These are existing product claims, not independently benchmarked findings.

## Operating Context

Visitors move from the landing page to documentation, installation, quick-start examples, and command tutorials. The source repository is linked at https://github.com/Tribrix23/CleaveDB.

## Capabilities and Constraints

- Existing documentation describes a Rust storage engine, ONNX embeddings, graph bonds, AVX-512 extensions, a Go coordinator, and document-level security.
- Existing command terminology includes POUR, FIND, SCOOP, LINK, CHANGE, buckets, documents, and bonds.
- Semantic embeddings are processed in the background; newly written documents can precede their semantic index.
- Preserve existing documentation and tutorial routes during the landing-page redesign.
- Examples and visual demonstrations must be identified as illustrative; the website is not connected to a live database.
- Performance benchmarks, adoption figures, customers, pricing, and licensing are unconfirmed. Do not fabricate them.
